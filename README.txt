FARSHAD Life OS — نسخه اولیه ۱.۰

محتوا:
- رمز عبور اولیه و قفل دستی
- ذخیره‌سازی محلی رمزگذاری‌شده با AES-GCM و کلید مشتق‌شده از رمز با PBKDF2
- روتین روزانه و تاریخچه فعالیت‌ها
- دفترچه یادداشت
- اهداف
- ثبت درآمد و هزینه
- پشتیبان‌گیری رمزگذاری‌شده و بازیابی
- انتخاب حالت ذخیره‌سازی گوشی / گوشی + پشتیبان ابری دستی

راه‌اندازی:
1) برای استفاده امن از Web Crypto و نصب PWA، فایل‌ها را روی یک میزبان HTTPS قرار بده.
2) با Chrome گوشی Samsung A53 آدرس برنامه را باز کن.
3) از منوی Chrome گزینه Install app یا Add to Home screen را بزن.
4) بار اول رمز عبور حداقل ۸ کاراکتری بساز.

نکات مهم:
- این نسخه یک اپلیکیشن شخصی local-first است. حالت «گوشی + ابری» در این نسخه یعنی تهیه فایل پشتیبان رمزگذاری‌شده و ذخیره دستی آن در Google Drive یا فضای دلخواه؛ همگام‌سازی خودکار ابری هنوز پیاده‌سازی نشده و به اتصال/راه‌اندازی سرویس ابری نیاز دارد.
- برای بازیابی، همان رمز زمان تهیه پشتیبان لازم است. اگر رمز را فراموش کنی و پشتیبان رمزگشایی‌پذیر نداشته باشی، داده‌ها قابل بازیابی نیستند.
- زبان‌های بیشتری در فهرست نمونه قرار دارند، اما ترجمه کامل فعلاً فقط فارسی است.
- پیش از وارد کردن اطلاعات بسیار حساس، از فایل پشتیبان رمزگذاری‌شده نسخه جداگانه نگه دار.
